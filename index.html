Comidas Típicas Cruceñas

Plato Bandera
Majadito

Preparado a base de arroz tostado con charque (carne seca desmenuzada), urucú que le da su color característico, acompañado de huevo frito y plátano maduro frito.

Tradicional
Locro Carretero

Sopa sustanciosa y reconfortante elaborada con arroz, charque o gallina criolla, cebolla verde y urucú. Ideal para compartir en familia.

Horneado / Brasa
Sonso de Yuca

Puré de yuca cocida mezclado con abundante queso chaqueño rallado, moldeado en un palo y asado a las brasas hasta quedar dorado.

Acompañamiento
Cuñapé

Panecillo tradicional horneado hecho con almidón de yuca y queso blanco. Es el compañero inseparable del café de la tarde en Santa Cruz.

Dato Cultural

Ciudad de los Anillos

Santa Cruz de la Sierra es mundialmente conocida por su diseño urbanístico radial y concéntrico, inspirado en las ciudades jardín europeas. Sus avenidas principales forman anillos circulares numerados (del 1° al 8° anillo y más) que rodean el casco viejo, conectados por avenidas radiales que parten desde el centro hacia las afueras.

// Guarda este código como api_santacruz.php en tu servidor local (XAMPP/Laragon) para persistir los cambios en MySQL:

<?php
header("Content-Type: application/json; charset=UTF-8");
$conexion = new mysqli("localhost", "root", "", "db_santacruz");

if ($conexion->connect_error) {
    die(json_encode(["error" => "Error de conexión: " . $conexion->connect_error]));
}

$accion = $_POST['accion'] ?? $_GET['accion'] ?? '';

// 1. Listar Reseñas Históricas
if ($accion === 'listar_resenas') {
    $res = $conexion->query("SELECT * FROM resenas_historicas ORDER BY id DESC");
    echo json_encode($res->fetch_all(MYSQLI_ASSOC));
}

// 2. Agregar o Modificar Reseña
if ($accion === 'guardar_resena') {
    $id = $_POST['id'] ?? '';
    $titulo = $conexion->real_escape_string($_POST['titulo']);
    $anio = $conexion->real_escape_string($_POST['anio']);
    $contenido = $conexion->real_escape_string($_POST['contenido']);

    if (empty($id)) {
        $conexion->query("INSERT INTO resenas_historicas (titulo, anio, contenido) VALUES ('$titulo', '$anio', '$contenido')");
    } else {
        $conexion->query("UPDATE resenas_historicas SET titulo='$titulo', anio='$anio', contenido='$contenido' WHERE id=$id");
    }
    echo json_encode(["status" => "ok"]);
}

// 3. Eliminar Reseña
if ($accion === 'eliminar_resena') {
    $id = intval($_POST['id']);
    $conexion->query("DELETE FROM resenas_historicas WHERE id=$id");
    echo json_encode(["status" => "eliminado"]);
}

// 4. Actualizar Configuración (Colores Verde-Blanco-Verde y Datos del Autor)
if ($accion === 'guardar_config') {
    $colorPrimario = $conexion->real_escape_string($_POST['color_primario']);
    $nombreAutor = $conexion->real_escape_string($_POST['nombre_autor']);
    $telefonoAutor = $conexion->real_escape_string($_POST['telefono_autor']);

    $conexion->query("UPDATE configuracion SET color_primario='$colorPrimario', nombre_autor='$nombreAutor', telefono_autor='$telefonoAutor' WHERE id=1");
    echo json_encode(["status" => "config_actualizada"]);
}
?>
