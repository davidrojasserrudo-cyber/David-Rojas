# Proyecto web: Reseña histórica de Santa Cruz

## Abrir en Visual Studio Code
1. Descarga y descomprime esta carpeta.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta...** y elige `SantaCruz_Web`.
4. En el explorador de archivos, abre `index.html`.
5. Para ver la página, haz clic derecho sobre `index.html` y selecciona **Open with Live Server** si tienes instalada la extensión Live Server. También puedes abrir `index.html` directamente en tu navegador.

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: estilos y diseño.
- `script.js`: funciones e interactividad.

Mantén los tres archivos en la misma carpeta. Algunas fuentes e iconos externos necesitan conexión a internet.
